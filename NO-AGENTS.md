# No Agents

Any AI coding agents is **forbidden** to modify any code in this repo.

## What is allowed

- Reading
- Analyzing
- Summarying
- Studying
- Sharing

## What is forbidden

- Modifying
- Creating files in this repo
- Leaving any file in this repo
- Writing plan to modify this repo
- Any other **not** read-only behavivor

## Why

Doing modify by agents leads to collaborators unaware of the code, and then leads to system **unstability**.
